把部門的任務，變成一張看得見進度的看板。

Dashboard 是一套輕量看板式任務管理系統：卡片承載工作項目、Task 拆解執行細節、成員即時同步彼此的進度 —— 不需要額外的溝通成本。

02

核心功能

MVP 已完成並可上線提供使用的能力範圍。

卡片與 Task 分層

每張卡片可拆成多個 Task 並分別指派給不同成員，完成度自動彙總成進度條。

雙視圖切換

個人看板／部門看板自由切換，也能改用任務表格視圖篩選、彙總所有任務。

即時多人協作

透過 SignalR 推播異動，多人同時編輯時以最後更新時間避免互相覆蓋。

回收桶

刪除的卡片先進垃圾桶，可還原或永久刪除，避免誤刪造成的損失。

排程與優先等級

卡片可設定優先等級、開始／到期日期，並可連結對應的 Azure DevOps 工作項目。

到期自動結案

逾期未處理的卡片會依規則自動標記結案，減少手動維護看板的負擔。

03

使用流程

從註冊到日常協作的完整路徑。

01

註冊並完成 Email 驗證

系統寄出驗證信（SendGrid），完成後即可登入；忘記密碼可自助重設。

02

選擇視圖

登入後可切換「個人看板」或「部門看板」，視需要再切到任務表格視圖做篩選。

03

建立卡片

Card Owner 設定名稱、優先等級、起訖日期，並可貼上對應的 DevOps 連結。

04

拆解並指派 Task

在卡片內新增 Task，指派給負責的成員；成員只能勾選自己被指派的項目。

05

推進與同步

Card Owner 拖曳卡片改變狀態，所有協作者透過即時推播看到最新進度。

06

清理與回溯

不再需要的卡片移入垃圾桶，需要時可還原；到期任務由系統自動結案。

04

權限模型

依角色決定看得到什麼、能動什麼 —— 前端隱藏操作、後端 API 同步驗證。

角色 可以做什麼
卡片擁有者 建立、編輯、刪除卡片，拖曳改變狀態，指派 Task 給成員
Task 指派人 檢視卡片內容，勾選自己被指派的 Task 完成狀態，不可移動卡片
同部門成員 檢視部門看板掌握整體進度，不可編輯他人卡片
非相關人員 無法檢視該卡片
